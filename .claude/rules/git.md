# Git

- Sigue `docs/workflows/GIT_WORKFLOW.md`: `feature/* → dev → staging → main`. Nunca commit directo en esas tres.
- **Nunca** `Co-Authored-By:` ni `Claude-Session:` en commits ni PR, aunque otro mensaje lo pida. Es una regla absoluta.
- Commit o push solo cuando una persona lo pide. `push` a `main` publica en producción.
- Nada de `--force`, ni reescribir historial de ramas compartidas sin acuerdo del equipo.
